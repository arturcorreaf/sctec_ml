# 📚 Exercícios do Curso

Esta pasta reúne os exercícios práticos desenvolvidos durante o curso de Machine Learning e Visão Computacional, organizados por semanas de estudo.

Cada subpasta representa uma semana e contém atividades relacionadas aos conteúdos estudados naquele período.

## 📂 Organização

- **S04** — Git, GitHub, Python local e estruturas de dados.
- **S05** — Arquivos, datas, expressões regulares (Regex), funções e módulos.
- **S06** — Pandas e NumPy: análise de dados em Python.


**Observação:** As pastas são atualizadas conforme o avanço dos estudos e a realização de novos exercícios.
